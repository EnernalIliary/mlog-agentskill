## 本轮发现并修复

1. **`selftest` 没有归一化坐标**（真 bug，已修）：`mschgen.selftest` 用绝对 tile 坐标比较原蓝图与重建蓝图，
   于是平移被算成不一致，输出 **176/430**。改为按包围盒原点归一化后比较（`_norm`），现为 **430/430**。
   这与 S-05 的历史结论一致，说明当时修的是别处、`selftest` 没跟上。
2. **`gen` 会自动给源文件签名**：`mlog.py gen` 默认调用 `aigenerated.sign()`，会改写 `--source` 文件（追加/替换
   `jump 0 always 0 "aigenerated:..."`）。R-10/R-11 的实验里源文件被原地改过一次，属预期行为，文档已写。
3. **`itemTake` 首次转移受 `Time.time` 门控**：`ItemTakeI` 先 `timeoutDone(unit, transferDelay)`，单位刚 spawn 时
   `Time.time` 还不够大，单条 `itemTake` 会静默失败；必须循环重试（约 30–40 tick 后成功）。L2-08 的 5 格/9 格
   对照就是靠循环才复现的。
4. **`ucontrol stop` 不是刹车**：stop 后 120 tick 仍有约 0.1 tile 的残余位移（drag 衰减），断言里的“继续滑行”成立，
   但幅度很小，不能拿它当“立刻停住”。
